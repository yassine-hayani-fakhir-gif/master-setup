Initial USB boot is required. Windows on the target may be missing or broken.
Clean installation erases the selected disk after explicit review.
Keep USB until the green release notice AFTER Windows and internal boot are prepared.
Remove USB, then enter Y to restart. Office/apps use copied local packages.

Build once on Windows with ADK + WinPE add-on using PE/Build-MasterPE.ps1.
This repository contains source, not a ready-to-boot WinPE ISO.
