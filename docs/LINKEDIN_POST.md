I’m building Master Setup, a Windows deployment assistant for my systems administration portfolio.

The goal: select Windows media, Office and application installers once, review the target disk, then follow the installation with clear progress and logs.

In my Windows VM tests, the app queue installed Brave, Chrome, VLC and WinRAR. The current preview also includes a four-language core interface, an installation review and optional blank-password account configuration.

This is still a preview. I’m validating Arabic interface switching, executable startup and Office completion handling before calling the release stable.

The project has taught me that automation is more than launching installers: handling failures, preserving user choices and verifying the target matter just as much.
